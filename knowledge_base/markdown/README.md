# Markdown 课程库

这里是对项目 `knowledge_base/scenes/*.json` 的无损 Markdown 转换。

- 场景课程：49 个
- 话术条目：928 条
- 全文入口：[知识库全文](知识库全文.md)
- 分类入口：[分类总览](分类总览.md)
- 原始结构化索引：../script_index.json

## 课程规则

每个 JSON 场景文件对应一门课；每个小技能目的对应一个 Markdown 二级章节。原文放在“话术原文”代码块内，保持原始内容不删减、不纠错、不改写。适用情绪、教练风格、表达层级、标签和技能类型放在场景标注中，供学习卡片检索。

## 互联网资料边界

当前八大分类各有足量课程条目，因此本批次不把外部网页文本混入原文库。若后续新增公开资料，应在独立来源记录中保存 URL、访问日期和授权/引用范围，再经过人工审核后进入课程。
