# 「对练社交」使用说明书

**版本：v2.4.5｜更新日期：2026-09-10｜适用范围：当前 Web 原型与 Android 模拟器预览**

## 1. 产品用途

本产品用于模拟社交场景和练习沟通表达。AI 反馈仅供训练参考，不构成医疗、心理、法律或其他专业意见，也不保证现实沟通结果。

## 2. 注册与首次使用

1. 在登录页选择“立即注册”，填写手机号、昵称和不少于6位的密码，并阅读同意相关协议。
2. 注册成功后查看欢迎引导。
3. 从可滚动的完整场景目录中免费选择1个。系统会再次提示这是唯一一次免费选择；确认后不可更换免费场景。
4. 解锁成功后选择“开始训练”立即进入，或选择“稍后再练”返回首页。
5. 其他场景需按卡片显示的学员等级、好感度折后可用积分和时空穿梭券条件解锁。学员等级依据累计等级进度积分计算，消费可用积分不会降级；模板市场和“更多训练场景”使用同一套条件。

刷新或重新登录后，已看过引导和已选择场景的状态应保留；若重复出现免费领取，请停止操作并反馈。

## 3. 首页

- “上次训练”显示最近开始的场景；无记录时引导选择项目。
- “选择训练项目”提供常用场景入口。首次选择显示“免费选择”，完成首次选择后显示开始或解锁条件。
- 签到和训练小贴士属于辅助功能，不影响训练主流程。
- 首页签到与签到日历奖励一致：基础签到获得10积分和1张穿梭券，连续签到第7天额外获得3张券（达到持有上限时以页面提示为准）。

## 4. 训练页

训练页包含六个一级功能区：

- 场景模板市场：进入后从精选训练或“更多训练场景”选择具体内容。
- 自定义场景：创建和管理个人场景；当前主要使用本地数据演示。
  - 创建额度按方案执行：免费/体验日卡1个、周卡5个、月卡10个、年卡不限；达到额度后会提示升级。
- 真实挑战：查看现实沟通挑战；每个项目会显示对应的环境背景、发生地点和教练扮演角色，进入对话页后头像、角色提示和场景背景保持一致。完成对话演练后需提交至少100字的现实行动复盘，可附2MB以内图片凭证；当前只保存在本机并标记为待审核，不发放本地/服务端奖励，服务端AI审核和奖励账本仍在完善。
- 我的作业：查看教练布置的专项训练。
- 学习卡片：训练功能区内的知识库课程。当前包含 49 个场景的 928 条结构化话术与《好好接话》78 个正文小技能及 18 张章节导语/速记辅助卡，共 1024 个可检索知识点；支持搜索、分类筛选、加载更多、收藏、取消收藏和复习。原始课程正文按原文展示并附安全边界提示。
- 社交礼仪训练：三世界九关卡的礼仪课程原型。每关提供故事、人物关系、场景目标和 A/B/C 参考选项，也可自由输入；提交后由教练给出即时评价。摄像头姿态识别、语音互动和服务端进度仍待后续更新。
- 语音训练：尚未完成，点击会提示等待更新。

## 5. 进行训练

1. 阅读对方消息和思考方向。
2. 用自己的语言输入回答，不建议机械照抄示范答案。
3. 查看本轮反馈后进入下一轮。
4. 完成规定轮次后查看训练报告。

首次训练可以体验示范回答和较完整分析；这不改变真实好感度等级。后续教学深度由好感度和会员权益共同决定。好感度负向扣减与场景折扣当前是标明“原型预览·未上线”的演示规则：解锁确认会展示原价、折后价和节省值，不会暗中扣除积分、穿梭券或会员权益；正式服务端审核、流水和跨设备权益尚未上线。

## 6. 退出与数据保存

训练中点击右上角“×”会显示退出确认：

- “继续训练”返回当前训练。
- “确认退出”结束本次训练。
- 当前未完成进度、本次积分和本次好感度不会保存。
- 免费用户在点击开始训练时即占用当天1次额度，退出不返还；每天00:00重置，会员不受免费额度限制但仍有安全限频。
- 中途退出不会额外扣除好感度。
- 好感度负向规则当前仅为“原型预览·未上线”：只在明确态度问题时扣减——同一训练连续3次明确敷衍回答扣3点，明确不当/攻击性内容扣5点；每类每次训练最多一次。低分、能力不足和使用穿梭券回退不扣已有好感度，扣减会即时提示并记录原因；正式服务端审核与申诉账本上线前，不将其视为跨设备生产权益。
- 连续3个未登录日后按每天1点衰减，单次重新登录最多补算7点；首次登录没有历史记录，不触发衰减。
- 当前版本不支持断点续训，下次需要重新开始该场景。
- 防沉迷设置会记录实际打开训练会话的时长。可在“我的→防沉迷”设置每日1/2/3小时限制或连续30/60分钟提醒；达到每日限制后训练锁定15分钟，成长数据和学习卡片仍可查看。设置仅保存在当前浏览器。

训练报告已生成后点击关闭可直接离开报告。

## 7. 好感度与权益

好感度表示教练对用户学习习惯和训练状态的了解程度，不是人格评价或现实能力证明。

| 等级 | 区间 | 主要教学权益 |
|---|---:|---|
| Lv.0 初识 | 0–19 | 基础对话训练；首次训练可体验示范回答 |
| Lv.1 熟悉 | 20–49 | 示范回答 |
| Lv.2 信任 | 50–79 | 完整分析 |
| Lv.3 默契 | 80–119 | 个性化教学 |
| Lv.4 师徒 | 120–179 | 复习挑战 |
| Lv.5 知己 | 180+ | 全部教学增益 |

非首次开始训练时，顶部会短暂显示当前等级、已解锁权益和下一等级提示。退出训练的确认框不会用好感度施压。

## 8. 积分、场景和时空穿梭券

- 积分用于学员成长和场景解锁，不等同于训练评分。
- “累计进度积分”只增不减，用于等级；“可用积分”用于解锁和兑换，消费后会减少但不会降级。免费用户累计获得积分上限为2000，会员有效期内不受该上限影响。
- 训练完成度低于70%或净得分低于30分时不发积分和好感度，但会保留反馈和训练记录；系统不会扣已有积分或降低等级。
- 同一场景每天第4次起积分减半；双倍积分卡仅在正常结算时消耗，失败结算不会扣卡。
- 时空穿梭券可用于特定解锁或纠错功能，具体消耗以操作前确认框为准。
- 免费/体验层用券解锁完整分析每日最多2次，跨日重置；同一份训练报告只允许解锁一次，避免重复扣券或重复发奖。
- 任何扣除必须先显示成本；余额不足时不应扣除。
- 场景解锁积分折扣当前仅为“原型预览·未上线”：按好感度等级计算，Lv.0 0%、Lv.1 10%、Lv.2 20%、Lv.3 30%、Lv.4 40%、Lv.5 50%。页面同时展示原价、折后价和节省值，实际扣除以确认时最新值为准并向上取整；正式服务端原子扣费和永久解锁账本尚未上线。
- “我的”中的道具背包会展示时空穿梭券、提示卡、情绪护盾和双倍积分卡的库存与用途；道具仅在训练中可使用，按钮会明确显示暂不可用原因。
- 道具使用上限：时空穿梭券每次训练最多2张且同一轮最多1张（完成至少1轮后可用）；提示卡每轮1张；情绪护盾每次训练1张且只对一轮负面评分减半；双倍积分卡每次训练1张且不可叠加。库存不足、超出上限或训练未达标时不会伪造奖励。
- 会员方案基线为体验日卡¥3.9/1天、周卡¥19.9/7天、月卡¥69/30天、年卡¥499/365天；当前支付未接入，方案按钮只会提示“支付接入中”，不会扣款或开通。
- 邀请奖励、分享积分、周期赠券/倍率、积分购买会员等尚未上线；邀请码页面当前仅记录入口，不承诺固定积分或道具。

### 8.1 训练前形象准备

进入任何训练项目后，会先看到“训练准备”页。这里可以查看当前真人全身头像，点击“选择 / 上传”更换预设或上传自己的全身照；头像卡片主体用于选择，右下角的放大按钮用于查看服装、姿态等细节。也可以打开“悦己颜值社（模拟预览）搭配”查看当前场景的穿搭、妆容和发型建议。真实悦己颜值社账号联动尚未上线，当前不会上传照片，也不会扣除积分、穿梭券或会员权益。

选择“使用当前形象开始”后才进入对话。训练报告会单独说明形象准备分及其评分贡献；形象只提供有限的场景适配加分，不替代对话能力评价，也不会因为未搭配而暗中扣分。

## 9. 教练、成长与个人中心

- 官方教练已绑定本地形象素材：半身照用于教练头像、教练选择和朋友圈动态；全身照用于训练对话顶部与教练消息。素材映射与维护说明见 `assets/images/coaches/README.md`，训练对话不会再随机替换当前教练形象。

- 教练页可查看和切换教练；每位教练分别记录好感度，并显示按自然日刷新的“今日任务”（场景训练、卡片复习、作业）。任务完成状态不会在当前原型额外发放奖励，服务端账本上线后再开放奖励。
- 成长页展示能力、日记、里程碑等内容；学习卡片已移到训练页，周进度使用已记录的训练天数，部分排行榜/挑战数据仍为原型演示。
- 个人中心包含会员、实名、隐私、防沉迷、反馈等入口；在“编辑资料”中可从9张不同气质的真人全身头像预设中选择，也可上传自己的全身照作为头像。预设头像按完整比例显示，上传支持 JPG/PNG/WebP、最大5MB，上传后会等比压缩并保留完整画面，点击“保存修改”才生效。照片仅保存在当前设备账号数据中，不会自动上传服务器；切换预设头像会清除照片头像。头像预设素材说明见 `assets/images/user-avatars/README.md`。客服 FAQ 已支持30条以上问题搜索，在线客服与反馈目前只保存本机演示记录，反馈可选择截图信息和页面日志但不会上传服务器；涉及外部服务的功能以页面实际状态为准。

## 10. 隐私与安全

- 不要在训练回答中输入身份证、银行卡、密码、精确住址等敏感信息。
- 上传照片或使用语音功能前，应确认页面明确说明用途和保存方式并取得授权。
- 如遇自伤、自杀、暴力或其他紧急风险，请立即联系当地紧急服务或合格专业人员，不要依赖本产品处理危机。

## 11. 常见问题

**注册后没有引导？**  
刷新页面后重新登录。若仍未显示，请记录浏览器、账号和发生时间反馈；不要反复注册。

**选错首次免费场景怎么办？**  
确认前可选择“再看看”；确认后当前规则不支持更换。

**为什么退出后没有积分？**  
未完成训练不结算积分或好感度，这是退出确认中明确展示的规则。

**为什么语音训练打不开？**  
语音训练尚未上线，点击会显示等待更新提示；社交礼仪训练已提供 Web 原型课程。

**页面数据和另一台设备不同？**  
当前 Web 原型部分数据使用浏览器本地存储；同一浏览器切换账号时会隔离场景、道具、日记、自定义场景和教练状态，但正式跨端同步仍在开发与验收。

## 12. 当前版本限制

当前版本是产品验证原型，不代表已经具备生产环境的支付、实名、短信、推送、多端同步、语音和完整内容审核能力。Android Debug APK 已可安装到项目 AVD 进行界面/流程测试，但尚未完成真实设备、弱网和后台恢复验收。最新真实状态见 `docs/development-plan.md`，学习者视角复审报告为 `docs/code-review-report-2026-09-04.md`，本轮 Flutter 模拟器续审报告为 `docs/code-review-report-2026-09-08.md`，营收/奖励/解锁规则专项报告为 `docs/revenue-rules-audit-2026-09-05.md`（最终复核日期：2026-09-08）；知识库课程化报告为 `docs/knowledge-base-conversion-report-2026-09-10.md`。

### Android 模拟器预览

本轮 Debug APK 使用显式 `DEMO_MODE=true` 供产品验收：演示登录后可检查首页首次项目选择、其他项目锁定提示、教练/场景、三轮文字训练、退出确认、训练结果、成长和会员中心。演示数据只保存在本地，不连接真实支付和生产账本；如要检查首次登录状态，可在模拟器中清除应用数据后重新启动。生产包默认关闭演示模式，必须配置真实 API 和鉴权。
