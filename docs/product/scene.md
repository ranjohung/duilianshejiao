## 6. 社交模拟场景系统

### 6.1 六大社交阶段

| 阶段 | 名称 | 核心能力 | 描述 |
|------|------|---------|------|
| 阶段一 | 破冰期 | 开启对话、第一印象 | 学习如何自然地开始一段对话 |
| 阶段二 | 接触期 | 维持对话、寻找共同话题 | 学习如何让对话持续下去 |
| 阶段三 | 熟悉期 | 深度交流、情感表达 | 学习如何表达真实的自己 |
| 阶段四 | 亲密期 | 冲突处理、深层共情 | 学习如何在矛盾中沟通 |
| 阶段五 | 职场期 | 职场沟通、专业表达 | 学习职场中的得体沟通 |
| 阶段六 | 高难期 | 压力沟通、谈判博弈 | 学习在高压场景中保持冷静 |

### 6.3 训练流程

```
开始训练
  │
  ▼
场景介绍（15秒）
  │  - 展示场景背景、对方角色、训练目标
  │
  ▼
对话轮次（核心环节，3-8轮）
  │  ┌─────────────────────────────────┐
  │  │  教练/AI角色说话                  │
  │  │         ↓                       │
  │  │  展示A/B/C三个选项               │
  │  │    A: 直接表达型                  │
  │  │    B: 委婉表达型                  │
  │  │    C: 回避/幽默型                 │
  │  │         ↓                       │
  │  │  用户选择 → 教练即时反馈           │
  │  │  （指出选择的优劣+改进建议）        │
  │  └─────────────────────────────────┘
  │
  ▼
评估报告
  │  - 总分(0-100)
  │  - 各维度得分
  │  - 星级评价(1-3星)
  │  - 优势亮点
  │  - 改进建议
  │  - 教练寄语
  │
  ▼
引导卡片
  │  - 本次训练的关键知识点
  │  - 可收藏、可分享
  │
  ▼
结束（返回场景页）
```

**选项设计规则：**

- A选项：直接/主动型——效果通常最积极，但需考虑场合
- B选项：委婉/间接型——社交安全但可能效果不足
- C选项：回避/幽默型——避免冲突但可能错过沟通机会
- 每轮选项设计必须体现不同的沟通策略，无绝对正确答案
- 选项效果根据场景上下文动态评估，不是固定得分

### 6.4 阶段解锁规则

阶段是学习路径和页面分组，不是自动解锁开关。首登免费选1个官方场景；后续每个场景单独校验最低等级（累计进度积分）、可用积分和时空穿梭券，确认后扣除资源并永久解锁。好感度等级对可用积分成本提供0/10/20/30/40/50%折扣（Lv.0–Lv.5），向上取整，券和累计等级积分不受影响；该折扣当前仅为“原型预览·未上线”，正式服务端账本未接管。会员仅在有效期内访问全部场景。

**解锁校验逻辑：**

1. 查询累计等级进度、可用积分和券余额
2. 计算当前场景三重条件并展示缺口
3. 条件满足后显示二次确认，按当前好感度重算折后积分；服务端事务扣除并写入唯一解锁记录（生产待实现）
4. 解锁后刷新场景列表并记入成就系统；阶段完成只用于推荐，不自动改写解锁状态

## 7. 高难度关卡系统

### 7.1 关卡列表

| 关卡名称 | 难度 | 类型 | 描述 |
|---------|------|------|------|
| 加薪谈判·被动型老板 | ⭐⭐⭐⭐⭐ | 职场 | 面对消极被动、不愿表态的老板争取加薪 |
| 加薪谈判·强势型老板 | ⭐⭐⭐⭐⭐ | 职场 | 面对强势压制、否定你价值的老板争取加薪 |
| 加薪谈判·认可型老板 | ⭐⭐⭐⭐ | 职场 | 面对已经认可你的能力、但以预算为由推脱的老板，如何突破他的借口争取加薪 |
| 投诉物业 | ⭐⭐⭐⭐ | 生活 | 向物业投诉长期未解决的问题 |
| 4S店砍价 | ⭐⭐⭐⭐⭐ | 生活 | 在4S店与销售谈判车辆价格 |
| 路边摊砍价 | ⭐⭐⭐ | 生活 | 在路边摊与摊主砍价 |
| 投诉客服 | ⭐⭐⭐⭐ | 生活 | 向客服投诉产品质量问题，争取合理赔偿 |

### 7.2 解锁与通关条件

| 项目 | 条件 |
|------|------|
| 解锁条件 | 按累计等级进度、可用积分和时空穿梭券三重校验；会员期内直接访问 |
| 通关条件 | 完成度≥70%且净得分≥30；三星是额外奖励条件 |
| 重试机制 | 每次开始训练消耗1次当日额度，中途退出不返还；会员仍受安全限频 |
| 奖励 | 有效训练基础约20–50积分；净得分≥80额外+10，首次三星额外+20；未达标不发本次积分/好感度 |

### 7.3 高难度关卡特殊设计

- **多分支结局**：根据关键选择节点，产生2-3种不同的对话走向
- **突发事件**：对话中随机插入意外情况（如对方突然发怒/提出额外要求）
- **时间压力**：部分关卡设置回复倒计时，模拟真实压力
- **NVC强制应用**：特定轮次要求使用NVC四步法，否则扣分
