## 13. 时空穿梭与学习卡片系统

### 13.1 时空穿梭

**功能描述：** 在训练对话中，用户可以使用"时空穿梭券"回到关键分支点，重新选择不同的对话选项。

**使用流程：**

1. 训练中，每轮选择后显示"穿梭"按钮
2. 点击"穿梭"→消耗1张时空穿梭券
3. 画面出现时空倒流动效
4. 回到该轮选择前，重新展示A/B/C选项
5. 用户重新选择，教练基于新选择继续对话
6. 原选择和新选择的对比展示（可选）

**限制规则：**

- 每次训练最多使用2张
- 只能回退到当前轮次，不能跨轮回退
- 使用穿梭券不影响训练评分（鼓励试错学习）
- 穿梭后教练会特别点评两个选择的差异

**时空穿梭券获取方式：**

| 获取渠道 | 数量 | 说明 |
|---------|------|------|
| 每日签到 | 每日1张（第7天额外3张） | 当前 Web 原型已实现 |
| 周/月/年会员 | 生产待实现 | 需权益账本按周期发放 |
| 邀请好友 | 生产待实现 | 需服务端审核后发放 |

### 13.2 学习卡片

**自动生成规则：**

- 每次训练结束后自动生成1张学习卡片
- 卡片内容由LLM基于训练过程提取

**卡片内容结构：**

```
┌──────────────────────────────────┐
│  📋 学习卡片                      │
│  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  │
│  标题：如何在面试中展示自信         │
│  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  │
│  关键知识点：                      │
│  • 开场时保持眼神接触             │
│  • 用具体事例代替空泛描述          │
│  • 回答前先停顿1-2秒组织语言      │
│  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  │
│  你的表现：                        │
│  ✅ 能用具体例子支撑观点           │
│  ⬆️ 回答前可以多停顿思考           │
│  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  │
│  改进建议：                        │
│  尝试使用STAR法则组织回答          │
│  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  │
│  [收藏]  [分享]                   │
└──────────────────────────────────┘
```

**卡片操作：**

- **收藏**：加入我的学习卡片集，方便复习
- **分享**：生成精美图片，分享到社交平台
- **复习**：重新查看卡片内容；当前 Web 仅结算 +1 好感度 +5 可用/累计积分，才艺经验待服务端账本上线

### 当前 Web 原型实现（2026-09-10）

- 学习卡片已归入训练功能区，支持关键词搜索、分类筛选、分页加载、收藏、取消收藏和复习入口。
- 卡片数据由 49 个结构化场景的 928 条话术与《好好接话》正文的 78 个小技能课程及 18 张章节导语/速记辅助卡合并组成，共 1024 个知识点；每个《好好接话》小技能正文保持原文并作为一张课程卡片。
- 卡片展示同时提供场景、原文表达、原则、练习提示和安全边界；搜索覆盖标题、场景、正文、原则、标签和练习提示。
- 当前为本地原型，卡片收藏/复习保存在当前浏览器；LLM 自动生成卡片、服务端同步、内容审核和跨设备一致性仍待生产闭环。
