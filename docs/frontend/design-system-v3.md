# 前端设计系统 v3

**更新日期：2026-09-04｜适用实现：`index.html`**

## 设计方向

保留紫—粉品牌渐变，以 shadcn/ui 的信息层级、Radix UI 的交互状态、Apple HIG 的触控尺寸和 Material 3 的自然动效为参考。当前项目保持无构建的单文件架构，先通过设计令牌与统一组件规则完成低风险重构；后续框架迁移不得改变业务规则。

## 核心令牌

- 品牌主色：`#7c3aed`；深色：`#6d28d9`；强调色：`#ec4899`。
- 正文：`#172033`；次级文字：`#667085`。
- 页面背景：`#f8f7fb`；卡片：`#ffffff`；边框使用低对比紫灰透明色。
- 圆角：10/14/20/28px 四级。
- 阴影：仅使用 xs/sm/md/lg 四级，避免每张卡片使用不同阴影。
- 动效曲线：`cubic-bezier(.22,1,.36,1)`；支持 `prefers-reduced-motion`。

## 组件规则

- 底部导航使用浮动玻璃表面，当前项同时使用颜色、背景和 ARIA 状态区分。
- 所有按钮最小高度40px，必须有键盘焦点态、按压态和禁用态。
- 输入框统一边框、悬停和焦点环；不得只依赖颜色表达错误。
- 卡片使用统一边框、圆角和阴影；渐变只用于关键主入口和品牌区域。
- 弹窗统一模糊遮罩、24px圆角和自然进入动效，动态弹窗必须声明 `role=dialog`。
- 未完成功能显示“即将上线”，点击后给出明确反馈，不进入空页面。

## 页面结构

- 登录：品牌识别区 + 独立身份卡片，注册引导默认不得遮挡表单。
- 首页：身份与教练摘要 → 上次训练 → 训练项目 → 辅助内容。
- 教练：页面标题 → 教练主体 → 核心动作 → 次级动态。
- 训练：一级功能中心 → 二级场景/自定义内容，避免在同一屏混合两层导航。
- 成长：关键进度优先，详细统计和辅助练习下沉。
- 我的：身份资产卡优先，账户、权益和设置使用统一列表表面。

## 验收

- 430px移动视口和桌面居中容器均可用。
- 注册、首次选择、训练、退出两条Playwright主流程通过。
- 登录页无浮层拦截主要操作。
- 键盘焦点清晰；减少动效系统设置生效。
