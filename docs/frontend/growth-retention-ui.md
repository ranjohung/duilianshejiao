# 成长与留存UI

> 来源：PRD v2.0 第8-9章、第13章、第17章

> **v2.4.2 规则校准：** 训练、签到和道具限制为当前 Web 原型可用规则；好感度负向规则和场景积分折扣已开发为“原型预览·未上线”，正式服务端审核、流水、跨端同步和原子扣费待实现。分享、才艺经验、会员周期道具和邀请付费奖励仍是生产待实现，不在界面中承诺固定收益。

## 训练积分与学员等级系统

### 训练积分获取

| 行为 | 积分 | 说明 |
|------|------|---------|
| 完成场景训练 | 约20-50分 | 完成度≥70%且净得分≥30；免费每日5次，会员按方案/安全限频 |
| 每日签到 | 10分+1张券 | 每日1次；券受持有上限约束 |
| 连续签到7天额外奖励 | 额外3张券 | 第7天额外获得，受持有上限约束 |
| 完成挑战任务 | 以服务端 `reward_points` 为准 | 每个挑战仅一次 |
| 分享学习卡片 | 生产待实现 | 当前仅分享内容，不发积分 |
| 高难度关卡首通 | 生产待实现 | 当前按普通场景训练结算 |
| 真实挑战完成 | 以服务端配置为准 | 审核、防刷和账本上线后发放 |

### 学员等级

| 等级 | 累计积分 | 等级图标 | 解锁权益 |
|------|---------|---------|---------|
| 青铜 | 0 | 🥉 | 基础功能 |
| 白银 | 100 | 🥈 | 解锁自定义教练 |
| 黄金 | 200 | 🥇 | 解锁高难度场景门槛 |
| 铂金 | 400 | 💎 | 解锁语音训练（当前页面仍显示“即将上线”） |
| 钻石 | 600 | 👑 | 高阶训练门槛（会员权益另计） |
| 大师 | 800 | ⭐ | 大师称号与成就 |

**等级与积分消耗说明：** 训练积分消耗（如创建自定义教练消耗100积分）不影响学员等级。等级仅根据累计获得的积分决定，消耗积分不会导致降级。

### 每日训练次数上限

| 会员等级 | 每日训练次数 |
|---------|------------|
| 免费用户 | 5次 |
| 体验日卡用户 | 20次 |
| 周卡用户 | 无限 |
| 月卡用户 | 无限 |
| 年卡用户 | 无限 |

**次数重置**：每日 00:00 重置
**计数方式**：开始训练即消耗1次，中途退出不返还

会员“不限”不等于无限制调用，仍受服务端安全限频和成本保护。

**奖励口径**：等级进度积分（累计获得、只增不减）与可用积分（解锁/兑换余额）分离；免费用户等级进度累计上限2000分。低于结算条件不扣已有积分、不降低等级，只不给本次奖励。

**好感度负向与场景折扣（Web 原型预览·未上线）：** 只对明确态度问题扣减：同一训练连续3次明确敷衍回答-3、明确不当/攻击性内容-5，各自每次训练最多一次；低分、能力不足、退出和穿梭券回退不扣。连续3个未登录日后按每天-1，单次登录最多补算7点；扣减即时提示并记录原因，范围0–200。场景解锁可用积分按 Lv.0–Lv.5 提供0/10/20/30/40/50%折扣，向上取整，页面展示原价/折后价/节省值；累计等级积分、穿梭券和会员访问不受影响。服务端审核、流水和原子扣费仍待上线。

### 防沉迷与连续使用提醒

我的页提供两个本机原型设置：每日训练时长上限（0 表示不限制）和连续训练提醒。设置会写入当前账号的本地数据，并在开始训练前、训练计时过程中校验；达到上限时阻止继续开新训练，连续训练达到提醒阈值时显示休息提示。触发强制休息后默认等待15分钟，倒计时结束前不能重新开始训练。该计时仅统计本机 Web 原型的训练会话，生产版本必须改为服务端/客户端一致的可信时钟，并补充未成年人模式、家长控制、跨端同步和隐私说明。

### 教练今日任务

教练页显示按业务日重置的三项学习提醒：完成一次场景训练、复习一张学习卡片、完成一次作业。任务只记录学习进度，不在当前原型承诺额外积分、会员权益或现金奖励；完成状态写入当前账号本地数据。服务端上线后需要以幂等任务记录、时区规则和奖励账本为准，防止重复领取。

## 时空穿梭与学习卡片系统

### 时空穿梭

**功能描述：** 在训练对话中，用户可以使用"时空穿梭券"回到关键分支点，重新选择不同的对话选项。

**使用流程：**

1. 训练中，每轮选择后显示"穿梭"按钮
2. 点击"穿梭"→消耗1张时空穿梭券
3. 画面出现时空倒流动效
4. 回到该轮选择前，重新展示A/B/C选项
5. 用户重新选择，教练基于新选择继续对话
6. 原选择和新选择的对比展示（可选）

**限制规则：**

- 每次训练最多使用2张
- 只能回退到当前轮次，不能跨轮回退
- 使用穿梭券不影响训练评分（鼓励试错学习）
- 穿梭后教练会特别点评两个选择的差异

**时空穿梭券获取方式：**

| 获取渠道 | 数量 | 说明 |
|---------|------|------|
| 每日签到 | 每日1张（第7天额外3张） | 签到奖励 |
| 周/月/年会员 | 生产待实现 | 需权益账本按周期发放 |
| 邀请好友 | 生产待实现 | 需服务端审核后发放 |

### 真实挑战

| 项目 | 规格 |
|------|------|
| 定义 | 线下真实社交任务 |
| 示例 | "今天主动和一位同事聊天5分钟""在咖啡厅向陌生人搭话" |
| 完成方式 | 上传文字描述/图片凭证 |
| 审核方式 | AI教练自动验证（关键词+图片分析） |
| 奖励 | 以服务端 `reward_points` 为准；对应才艺经验待服务端审核/账本上线 |
| 频率 | 每日最多完成1个，不可重复完成 |

**真实挑战完成流程：**

1. 用户查看本周挑战列表（Tab4成长页→真实挑战）
2. 选择挑战任务，点击"开始挑战"
3. 用户在线下完成任务
4. 回到App，点击"打卡完成"
5. 用户填写文字描述（100字以上）+ 可选上传图片
6. AI教练自动验证（关键词+图片分析）
7. 验证通过 → 由服务端按挑战配置结算积分；本地演示提交后只记录“待审核”，验证前不发放本地或服务端奖励；才艺经验未上线前不显示为已获得
8. 验证不通过 → AI给出建议，用户可重新提交
9. 每个挑战不可重复完成；当前 API 未承诺全局“每日1个”固定上限，若上线该限制需由服务端按业务日强制执行

当前 Web 原型会在模拟挑战结算前要求提交不少于100字的文字说明，可选上传不超过2MB的图片；提交结果标记为“本地演示待审核”，不会伪造 AI 审核通过、服务端积分或才艺经验。正式版必须由服务端保存凭证、执行内容/图片审核、幂等结算和申诉留痕。
