## 社交模拟场景系统

> **真实挑战凭证状态（2026-09-07）：** 模拟挑战在 Web 原型中提交前必须填写不少于100字的真实经历说明，可选附加不超过2MB的图片；本地仅保存文件名、大小和提交状态，不上传、不宣称已完成 AI 审核，也不会绕过服务端奖励账本。正式环境必须接入服务端凭证存储、审核、幂等奖励和申诉流程。

> **真实挑战场景化状态（2026-09-08）：** 当前 Web 原型的 45 个挑战项目均按标题和训练分类绑定本地环境背景、地点、角色和语气提示。办公室、咖啡馆、兴趣社群、家庭、服务窗口、市场、汽车展厅、家中和公开活动共 9 组 JPG 素材位于 assets/images/challenges；卡片和对话页共用同一映射，教练头像切换为该场景中的角色。未知项目按分类回退，图片无法加载时保留渐变背景与文字。角色一致性、服务端下发配置、素材审核和 CDN 缓存仍属于生产联调事项。

### 训练流程

```
开始训练
  │
  ▼
场景介绍（15秒）
  │  - 展示场景背景、对方角色、训练目标
  │
  ▼
对话轮次（核心环节，3-8轮）
  │  ┌─────────────────────────────────┐
  │  │  教练/AI角色说话                  │
  │  │         ↓                       │
  │  │  展示A/B/C三个选项               │
  │  │    A: 直接表达型                  │
  │  │    B: 委婉表达型                  │
  │  │    C: 回避/幽默型                 │
  │  │         ↓                       │
  │  │  用户选择 → 教练即时反馈           │
  │  │  （指出选择的优劣+改进建议）        │
  │  └─────────────────────────────────┘
  │
  ▼
评估报告
  │  - 总分(0-100)
  │  - 各维度得分
  │  - 星级评价(1-3星)
  │  - 优势亮点
  │  - 改进建议
  │  - 教练寄语
  │
  ▼
引导卡片
  │  - 本次训练的关键知识点
  │  - 可收藏、可分享
  │
  ▼
结束（返回场景页）
```

### 训练次数与防沉迷校验

开始训练前依次校验账号状态、会员有效期/安全限频、当日训练次数和本机防沉迷设置；次数在真正进入训练时消耗，中途退出不返还。当前 Web 原型会记录训练会话时长，达到用户设置的每日上限后阻止新训练，连续训练提醒可要求休息15分钟。此规则仅为本机原型能力，生产必须由服务端统一计时、扣次和审计，不能依赖可篡改的前端状态。

**弹窗组件：**

- 函数：`showTrainingReminderModal()`
- 配置函数：`getFavorabilityConfig(level)` 返回 `{name, icon, bgClass, bgLight, borderClass, textColor, features[], nextFeature}`
- 触发位置：`startTraining()` 函数中，检查 `userData.hasStartedTrainingBefore`
- 关闭方式：用户点击"开始训练"按钮，调用现有横幅关闭逻辑 `closeFavorabilityBanner()`

**选项设计规则：**

- A选项：直接/主动型——效果通常最积极，但需考虑场合
- B选项：委婉/间接型——社交安全但可能效果不足
- C选项：回避/幽默型——避免冲突但可能错过沟通机会
- 每轮选项设计必须体现不同的沟通策略，无绝对正确答案
- 选项效果根据场景上下文动态评估，不是固定得分

### 阶段解锁规则

阶段只用于学习路径和页面分组。首登免费选择1个官方场景；后续场景逐项校验累计等级进度、可用积分和时空穿梭券，确认后按好感度计算0/10/20/30/40/50%积分折扣（Lv.0–Lv.5，向上取整），扣除资源并永久解锁。该负向扣减/折扣目前仅是标注“原型预览·未上线”的 Web 演示规则，正式服务端权益账本尚未接管；会员仅在有效期内直接访问全部场景。

**解锁校验逻辑：**

1. 查询累计等级进度、可用积分和券余额
2. 计算三重条件与好感度折后成本，并展示缺口、原价和节省值
3. 条件满足后显示二次确认；生产由服务端事务扣除折后积分/券并写入唯一解锁记录
4. 刷新场景列表；阶段完成只用于推荐，不自动改写解锁状态

### 解锁与通关条件

| 项目 | 条件 |
|------|------|
| 解锁条件 | 按累计等级进度、可用积分和时空穿梭券三重校验；会员期内直接访问 |
| 通关条件 | 完成度≥70%且净得分≥30；三星是额外奖励条件 |
| 重试机制 | 每次开始训练消耗1次当日额度，中途退出不返还；会员仍受安全限频 |
| 奖励 | 有效训练基础约20–50积分；净得分≥80额外+10，首次三星额外+20；未达标不发本次积分/好感度 |

### 高难度关卡特殊设计

- **多分支结局**：根据关键选择节点，产生2-3种不同的对话走向
- **突发事件**：对话中随机插入意外情况（如对方突然发怒/提出额外要求）
- **时间压力**：部分关卡设置回复倒计时，模拟真实压力
- **NVC强制应用**：特定轮次要求使用NVC四步法，否则扣分

## 语音训练系统

### 技术架构

```
用户语音输入
  │
  ▼
声网Agora RTC (采集+传输, <500ms)
  │
  ▼
语音识别 (ASR)
  │
  ▼
文本
  │
  ▼
LLM分析 (对话内容+语速+音量+停顿)
  │
  ▼
TTS合成 (Azure TTS, 教练音色)
  │
  ▼
教练语音回复 (Agora RTC播放)
```

### 语音训练模式

**流程：**

1. 教练提出问题（语音+文字同步）
2. 用户语音回答（最长60秒/轮）
3. 系统实时语音识别转文本
4. LLM分析回答内容 + 语速 + 音量 + 停顿
5. 教练给出语音反馈（内容评价+表达建议）
6. 进入下一轮

**语音分析维度：**

| 维度 | 分析内容 | 评分影响 |
|------|---------|---------|
| 语速 | 过快(>5字/秒)/过慢(<2字/秒)/适中 | 表达力±5 |
| 音量 | 过大/过小/适中 | 沟通力±3 |
| 停顿 | 合理停顿(思考)/过多停顿(紧张) | 应变力±5 |
| 流畅度 | 结巴次数/重复次数 | 表达力±5 |

### 语音训练权限

- 累计等级进度积分≥400（铂金学员）后可申请解锁；当前 Web 入口仍显示“即将上线”
- 周卡/月卡/年卡会员在有效期内直接访问
- 免费/体验日卡用户需达到铂金等级
- 正式接入后每次开始占用1次当日训练额度；不得通过语音入口绕过免费额度

**教练挂断机制说明：**
训练积分≤15属于极端情况下的兜底设计，在实际用户场景中极少发生。触发后教练不会直接挂断，而是先进行温和提醒（如"我注意到你似乎有些困扰，要不要换个方式试试？"），如果用户持续使用不当语言或连续冷场，才会触发挂断。

### 语音训练分阶段实施

| 阶段 | 能力 | 说明 |
|------|------|------|
| MVP | AI教练语音播放(TTS) + 用户文字回复 | 教练用语音"说话"，用户仍用文字回复，降低技术复杂度 |
| V1.1 | 完整语音训练(用户语音输入+ASR识别+教练语音回复) | 集成Agora RTC+ASR，实现全双工语音对话 |

## 训练前形象准备与头像预览

场景卡片点击开始后进入 `modal-prepare`，先展示用户当前真人全身形象、场景适配度和入口按钮。编辑资料头像画廊使用紧凑卡片降低视觉占用；卡片主体选择头像，右下角放大按钮打开 `modal-avatar-detail` 查看细节。`悦己颜值社`当前为模拟预览，页面明确等待账号接入且不会上传照片或扣除权益。选择“使用当前形象开始”后才创建训练会话；结算报告单列形象准备分和贡献，避免用户猜测评分来源。
## 训练中心控制台布局（2026-09-10）

训练中心使用“核心入口 + 专项卡片”层级：场景模板市场占满一行，作为用户最常用的训练入口；真实挑战、学习卡片、我的作业、社交礼仪训练、语音训练等以两列卡片呈现。核心入口使用紫色渐变建立品牌锚点，专项卡使用浅底、左侧色彩标记和状态徽章区分功能，不改变既有点击、锁定、额度或待上线逻辑。页面在 360px 以上保持两列，小屏收紧卡片内边距；支持 `prefers-reduced-motion`。
