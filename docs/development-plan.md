# 「对练社交」开发计划

**版本：v2.5.0｜校准日期：2026-09-13**

**产品基准：`docs/prd.md`｜当前可运行原型：`index.html`**

> 本计划区分“原型已实现”和“生产已完成”。HTML 中可点击、可用本地数据演示，不等于后端、支付、推送、内容审核或多端同步已经达到上线标准。

> **好感度规则/场景折扣上线状态：** 两项已完成 Web 原型逻辑和可见提示，但正式服务端审核、申诉、跨设备同步、原子扣费与永久解锁账本均未上线；当前不会暗中扣除积分、穿梭券或会员权益。

## 1. 状态定义

| 状态 | 含义 |
|---|---|
| ✅ 已验证 | 已实现，并有自动化测试或可重复验收证据 |
| 🟡 原型可用 | HTML/本地存储中可演示，生产接口或异常处理尚未完成 |
| 🚧 开发中 | 已有部分代码，但链路未闭环或未通过验收 |
| ⏳ 待开发 | 尚未实现；入口应显示“即将上线/等待更新” |
| 🔍 待核验 | 存在代码或文档声明，但缺少联调、测试或部署证据 |

完成标准：功能、数据持久化、异常处理、安全校验、埋点及验收测试全部通过后，才能标为“✅ 已验证”。
