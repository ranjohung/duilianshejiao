## 3. 模拟器门槛结论

**结论：可以开始由产品人员进行 Android 模拟器 UI/流程验收。**

该结论只覆盖 Debug APK 和 `DEMO_MODE=true` 的本地演示数据，适合检查布局、导航、提示时机和训练交互。以下项目仍不得标为生产完成：真实短信/密码鉴权与刷新 Token、真实 API/数据库、微信虚拟支付下单与回调验签、积分/好感度/解锁原子账本、语音权限与 RTC、内容安全、隐私合规、真实设备弱网/后台恢复和发布签名。

## 4. 后续验收顺序

1. 在真实 API 环境运行同一条登录→选场景→训练→结算链路，并补 API 契约、鉴权、幂等和错误码测试。
2. 接入微信虚拟支付沙箱，验证订单、回调验签、退款、过期降级、跨设备权益和对账。
3. 使用 Android 真机检查权限、键盘/刘海屏适配、弱网、切后台恢复、录音隐私和性能。
4. 再生成签名包，执行安全、内容审核、隐私和灰度发布门槛。
