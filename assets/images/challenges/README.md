# 真实挑战场景背景

这些图片是“真实挑战”训练的本地离线场景素材，统一使用宽幅、无人物、无品牌文字的构图，让教练头像和对话内容承担角色表达，背景负责提供环境线索。

| 文件 | 适用场景 | 教练角色 |
| --- | --- | --- |
| office.jpg | 面试、加薪、汇报、同事协作、职场冲突 | 王教练：直属上级或面试官 |
| cafe.jpg | 相亲、约会、表白、纪念日 | 李教练：相亲对象或约会对象 |
| community.jpg | 兴趣社群、聚会、婚礼、建立联系 | 林教练：主持人或新朋友 |
| family.jpg | 见家长、家庭聚会、父母/亲戚沟通 | 李教练：家人或长辈 |
| service.jpg | 客服、物业、退换货、医院、银行、政务、租房 | 张教练：客服、店员或办事人员 |
| market.jpg | 路边摊等轻消费谈判 | 张教练：摊主或销售人员 |
| auto.jpg | 4S 店谈价 | 张教练：销售顾问 |
| home.jpg | 共情、倾听、关系修复、数字社交 | 李教练：朋友或亲密关系对象 |
| public.jpg | 公开表达、线上会议、紧急求助 | 林教练：主持人、听众或现场工作人员 |

映射规则位于 index.html 的 challengeSceneCatalog 和 challengeSceneRules。服务端返回的未知项目会按训练分类回退到默认场景；图片加载失败时卡片仍保留渐变背景和完整文字信息。

素材为本项目定制生成的演示资产，当前仅用于本地原型和模拟器验收；正式发布前仍需完成素材版权、内容安全和 CDN 缓存审核。
